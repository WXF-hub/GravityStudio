# 万有引力事务所 · PDF 预览与分享版

保留了上一版的凸透镜成像、光的折射实验、首页自定义文案和开场动画。仅升级学习资料的交互：

- 点击 **预览**：在弹窗使用浏览器内置 PDF 阅读器阅读。
- 点击 **转发到微信 / 分享**：在支持 Web Share API 的移动浏览器调出系统分享面板；如不支持则复制公开 PDF 链接，粘贴到微信聊天发送。**普通网页不能强制直接打开微信指定联系人或自动转发文件。**
- 点击 **保存到本地**：使用同源 PDF 下载链接和 `download` 属性；Safari、微信内置浏览器可能改为打开 PDF，可通过“浏览器打开”之后的系统分享菜单选择存储到文件。
- 点击 **浏览器打开**：遇到 iframe 无法显示时，改用浏览器原生 PDF 查看器。
- 资料仍通过 GitHub API 自动列出 `WXF-hub/GravityStudio` 的 `materials` 文件夹；新增 PDF 不需要修改代码。

## GitHub Pages 更新
只需覆盖仓库根目录的 `index.html`、`js/materials.js` 和 `css/site.css`。文件夹结构不变，其他资料及实验文件保留。

## 注意
直接双击本地 HTML 时 GitHub API 仍尝试读取线上仓库的文件；完整功能应在 HTTPS GitHub Pages 地址测试。浏览器和微信版本对 PDF 预览、系统分享、下载的支持可能不同。GitHub 的静态托管不提供权限控制，公开资料链接可被访问和转发。
